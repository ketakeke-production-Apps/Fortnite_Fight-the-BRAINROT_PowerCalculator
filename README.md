# Fortnite Fight the BRAINROT Power Calculator

Fight the BRAINROT（ブレインロットファイト）のブレインロット戦闘力を計算・逆算するための静的Webアプリです。

## 使い方

このrepoはブラウザーで動く**静的Webアプリ**です。[index.html](index.html) をブラウザーで開いて使用できます（外部パッケージの導入不要）。GitHub Pagesへのデプロイ履歴はありますが、この案内では現在の公開URLや対応ブラウザーの動作を未検証のまま保証しません。

1. **「ベースから計算」**：ベース戦闘力を入力し、変換したい凸（★など）・属性・変異を選ぶと、切り上げ後の戦闘力を計算します。
2. **「出現値から逆算」**：現在表示されている戦闘力と、現在の凸・属性・変異を設定した後、変換先の凸・属性・変異を選ぶと、推定される変換後の戦闘力を表示します。
3. +0.1変異は**0・1・2種類**、+0.2変異は**なし・あり**から選択します。属性「Yokai」は倍率**1.8**で、計算・逆算の初期属性に選択されています。
4. **逆算の注意**：戦闘力は切り上げた整数のため、元のベース戦闘力が1つに確定しない場合があります。画面に示される整数候補・変換後の範囲を確認してください。

入力内容の変更時に画面の結果が更新されます。これらは`index.html`の実装に基づく説明であり、ゲーム本体の最新倍率や各ブラウザーの実機動作を新たに検証した結果ではありません。

## 計算式

```text
ceil(ベース戦闘力 × (凸倍率 + 属性倍率 - 1 + +0.1変異数 × 0.1 + +0.2変異数 × 0.2))
```

例：777 を ★5 Pirate（変異なし）にした場合

```text
ceil(777 × 1.7 + 777 × (2.8 - 1)) = 2720
```


## 変異倍率

- 戦闘力倍率 +0.1 の変異は、0・1・2種類から選択できます。
- 戦闘力倍率 +0.2 の変異は、なし・ありから選択できます。
